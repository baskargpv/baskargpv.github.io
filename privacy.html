Privacy Policy — Job Seeker Agent

Last updated: 17 November 2026

Job Seeker Agent is a personal tool used only by its owner. It has no other users.

Google user data

The app requests only the drive.file scope. It can see and change only the Google Drive files it creates itself: folders, job descriptions, resumes and cover letters. It cannot read any other file in Drive.

These files stay in the owner's Google Drive. They are not sold or shared with anyone, and are not used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
